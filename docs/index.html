How to use this marketplace in Seanime
  1. Open Seanime and go to the Extensions tab
  2. Click Change repository
  3. Paste this exact link:
https://raw.githubusercontent.com/Bas1874/Seanime-Marketplace/refs/heads/main/Marketplace/Main.json

You can revert to the official repo anytime by clicking Apply Default.

⚠ This marketplace is community-run — plugins are not manually reviewed. Everything is scanned by VirusTotal, but only install extensions from creators you trust.
